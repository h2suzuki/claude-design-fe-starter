# CAVEAT: 画面ジオメトリ安定原則

画面ジオメトリ（各要素の位置・サイズ・レイアウト）と表示内容は、人間が知覚・追跡できる形でのみ変化させる。知覚できない速さの変化や予告のない要素移動は、集中力を削ぐだけで何の役にも立たない（百害あって一利なし）。

本原則は全画面・全コンポーネントに適用する。FE 実装の発注書は本ファイルを必須参照に含めること。

## 禁止事項

- **一瞬だけ変化する表示**: ボタン押下時に一瞬だけ文言が変わる（例: 「保存」→「更新中…」→ 元に戻る）、フラッシュ的に出て消える表示、瞬間的な placeholder 差し替えを作らない
- **状態遷移に伴うレイアウトシフト**: 文言・表示内容の差し替えで要素の幅や高さが変わること、要素の出現・消滅で周辺要素が動くことを起こさない
- **スクロールバーの出没**: コンテンツ量や表示状態の変化でスクロールバーが現れたり消えたりして本体のレイアウトが揺れることを起こさない（常時表示か常時非表示に固定する）

## 実装指針

- 一定時間（目安 300ms）未満で完了する処理は、中間表示自体を出さない
- 処理中表示が必要なら、操作対象を無効化したまま安定した表示を維持する
- 出現・消滅しうる要素は表示領域をあらかじめ確保し、周辺要素を動かさない
- 文言が切り替わる要素は、最長の文言でも収まる寸法を確保する

## 検証観点

- 任意の状態遷移の前後でスクリーンショットを比較したとき、変化してよいのは意図した情報の中身だけ。要素の位置・寸法の変化や一瞬の中間状態が写り込んだら違反

## タブ毎の状態

画面選択・ナビゲーション・タブ内選択など、タブ毎の状態を localStorage に置かない。localStorage は全タブ共有であり、リロードが他タブの状態を復元する事故になる。per-tab 状態は sessionStorage または URL で保持する。localStorage に置いてよいのは全タブ共有が正しい非ナビゲーション設定のみ。

## 配色

- {{ドメインの意味色とテーマ切替の規則をここに定義する。例: 対になる意味色（成功/失敗・増加/減少 等）の割当と、テーマ設定で色が入れ替わる場合の規則}}
- アクセント・警告・予定・減光などの意味色は名前付きパレットから引く。同じ色でも意味が違えば別の名前で区別する。生の色コードを各所に書かず、パレットの名前を経由して参照する
- 配色の変更がパレット 1 箇所で完結すること。同じ色コードを複数箇所へ直書きしない。パレットの実体は `frontend/src/ui/tokens/tokens.css` とする

## 実装説明文の禁止

人間が直感で挙動を把握できず、実装説明に頼っている UI はゴミ UI です。実装説明しないですむ UI にしましょう。UI に実装の説明文を置かない。説明が必要になったら挙動を直す。

## 括弧の全角・半角（ガイドライン）

迷ったときの既定値を示す指針であって、ハードルールではない。この既定どおりにすると mock の UI で見た目が良くないなら、その mock が正。

- 全角の `（）` は周囲に空白を入れず、半角の `()` は前後に半角空白を入れて `文字 (中身) 文字` の形にするのが既定。全角は間延びして見えやすく、半角は詰まって見えやすいため
- 英文や半角数字の文字列の中なら半角。日本語の文字列の中なら全角
- 日本語の中でも括弧の中身が英文・半角数字だけなら半角。英文・半角数字の中でも中身に日本語が含まれるなら全角でもよい。中身の文字数も見る（例: 10 桁の数字に単位 1 文字なら、半角数字の文字列として扱う方が読みやすい）
- 最後は mock 上での見た目と桁揃えで判断する。上の既定に当てはまらない反例はあり得る

実例:

- `サーバ (serve) が起動しているか` — 中身が英字だけなので半角 + 前後空白
- `未分類（管理領域等）` — 中身に日本語を含むので全角
- 一覧のラベル `件数(累計)` `金額(税込)` `達成率(週次)` — 中身に日本語を含むが、mock が半角で桁を揃えているので半角
